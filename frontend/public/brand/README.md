# Brand Assets (`frontend/public/brand/`)

Place only official Valio Aimo logo files obtained from the Junction 2026 challenge kit or booth in this directory.
Never hotlink assets from `valio.fi`, never commit proprietary font files, and never trace the logo.
When no official file is present, the header renders the typographic wordmark **Valio Aimo** in iconic blue (`#002F6D`) with the open condensed font (`Barlow Condensed`) alongside the prototype disclaimer.
