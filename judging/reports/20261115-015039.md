## Verdicts

- **commercial**: The most trustworthy purchasing gateway I've seen: hard limits hold, injection attempts are logged, and every fact has its source. But on one plain macaroni order the agent misread stock its own API reported correctly, and it auto-ordered cheese 4 days early, so it isn't yet buying exactly what the kitchen asked for every time.
- **online-sales**: The most trustworthy agent gateway I've seen here: clear phone approvals, honest refusals and an open API. It loses points because a single Finnish typo can silently drop an allergen requirement.
- **tech-governance**: The most production-minded entry I saw: real OpenAPI and MCP, provenance on every fact, and guardrails that held when I attacked them directly. It still needs a tenant fix on one endpoint and must refuse to auto-order when the parser understood nothing.
